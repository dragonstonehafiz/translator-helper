Overview

Application components, processing flow and data storage.

Current implementation · 3 October 2026

Application structure

The app has two running parts: an Angular browser interface and a FastAPI Python backend. The browser gathers files, text and settings. The backend runs models, executes workflows and writes files. There is no database or separate durable job worker.

Angular pagesChoose inputs, start work and display results.
FastAPI routesValidate requests and arrange background work.
Tasks and modelsProcess audio, translate text or research library entries.
Files on diskKeep library data, generated subtitles and run logs.

The browser calls http://localhost:8000 through ApiService. Backend CORS permits http://localhost:4200. Model-provider and Tavily calls happen in the backend.

Browser memorySelected files, selected series, task state in StateService.Browser refresh. Route changes keep service state, but page-local state has its own lifecycle.

DiskLibrary JSON, settings JSON, generated subtitles, logs.Files persist independently of in-memory task state until removed or overwritten.

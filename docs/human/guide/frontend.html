Frontend architecture

Angular pages coordinate workflows. Services share state and HTTP access; reusable components handle presentation and interaction.

Current implementation · 3 October 2026

Application shell

AppComponent renders the navbar, router outlet, confirmation dialog, error dialog and progress overlay. The router replaces the page inside the outlet while the shell remains.

On initialization, the shell requests server variables. If the LLM or audio model is not ready, it navigates to Settings. Search readiness is tracked separately and is not part of that combined readiness check.

Source: frontend/src/app/app.component.ts.

Shared services

ServiceWhat it doesWhat it does not do
ApiServiceDefines HTTP methods and response interfaces; sends requests to the backend.Does not run the LLM or save library JSON locally.
StateServiceHolds shared values in RxJS BehaviorSubjects, which expose the latest value to subscribers.Polls the running workflow; does not persist state across a browser refresh.
ConfirmationServiceSupplies dialog state and resolves the user's decision.Does not itself delete the target file or library item.
ErrorDialogServiceSupplies error-dialog state for AppComponent.Does not determine whether a task succeeded; callers must report the failure.

Sources: frontend/src/app/services/api.service.ts and frontend/src/app/services/state.service.ts.

Shared and page-local state

StateService keeps model readiness, loading flags, settings schemas, selected series, original/translated subtitle files, file statistics and one state record per workflow: status, active task, progress, message, ETA, result and error.

StateService also owns the only polling loop. After a page's start request is accepted, it polls that workflow every second until it completes, fails or goes idle, and shows the error dialog on failure. The Translate page keeps only local form fields and download lists; it reads busy flags and results from StateService and refreshes its downloads when a workflow finishes.

Leaving Translate does not stop polling or cancel backend work. The progress overlay keeps updating, and the result is waiting when the user returns.

Source: frontend/src/app/pages/translate/translate.component.ts.

Refactoring dependencies

  • WORKFLOW_TYPES lists the backend workflow IDs. Adding a workflow means adding it on both sides.
  • The Settings page renders whatever fields the provider schemas declare, by type. Which provider fills each slot is chosen in backend/models/manager.py.
  • Download sections name backend folders directly. Moving outputs requires updating writers and these consumers together.
  • Library and Translate share selected subtitle files and series through StateService; those inputs are not entirely local to one page.

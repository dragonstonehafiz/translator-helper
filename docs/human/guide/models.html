Models

How ModelManager holds the LLM, audio and search clients, how provider settings are saved and loaded, and what each model exposes.

Current implementation · 4 October 2026

Model manager

ModelManager is a single shared object holding one LLM client, one audio client and one search client. Tasks see each slot only through its interface, so they call the same methods whichever provider is plugged in.

When a model is loaded, the manager creates the client if the slot is empty, applies and saves any submitted settings, then initializes it. For each slot it stores whether the model is loading, which task is using it, and the last loading error shown on the Settings page.

Changing the provider

Each slot's provider class is set at the top of backend/models/manager.py. To switch, uncomment the provider's import, assign it to the slot and restart the backend: 

from llm.claude import LLMClaude

LLM_PROVIDER: Callable[[], LLMInterface] = LLMClaude
AUDIO_PROVIDER: Callable[[], AudioModelInterface] = AudioWhisperX
SEARCH_PROVIDER: Callable[[], SearchTavily] = SearchTavily

Configuration

Each provider defines its settings as a ModelConfig dataclass, with one setting() per field giving the label, option type and default: 

@dataclass
class DeepSeekConfig(ModelConfig):
    CONFIG_FILE: ClassVar[str] = "llm_deepseek.json"
    PROVIDER: ClassVar[str] = "llm_deepseek"
    TITLE: ClassVar[str] = "DeepSeek"

    model_name: ConfigField[str] = setting("Model", DropdownOption((
        Choice("deepseek-v4-flash", "deepseek-v4-flash"),
        Choice("deepseek-v4-pro", "deepseek-v4-pro"),
    )), "deepseek-v4-flash", required=True)
    api_key: ConfigField[str] = setting("API Key", TextOption(password=True, placeholder="sk-..."), "", required=True)
    temperature: ConfigField[float] = setting("Temperature", NumberOption(min=0, max=2, step=0.1), 0.5)
  • Loading: the provider's constructor calls load(), which reads backend/files/config/<CONFIG_FILE>. If the file is missing, it is created with the defaults.
  • Saving: when the Settings page loads a model, the submitted values are validated and written back to the same file. If any value is invalid, nothing changes.
  • Settings form: the Settings page builds its form from these fields. Password values are never sent to the browser.
Option typeSettings control
TextOptionText input, or a password input with password=True
NumberOptionDecimal number with optional min, max and step
IntegerOptionWhole number with optional min and max
BooleanOptionToggle
DropdownOptionFixed list of choices, or a function that lists them when the form is built

infer()

Sends one request to the LLM and waits for the full reply.

NameTypeDescription
inputpromptstrThe user message.
inputsystem_promptstr | NoneOptional system message sent before the prompt. Default None.
inputtemperaturefloat | NoneOverrides the saved temperature for this call only. Default None uses the saved value.
inputmax_tokensint | NoneCaps the reply length for this call only. Default None means no cap.
outputstrThe model's reply text.

Search

Tavily is the only search provider and has no interface. Its only setting is the API key.

search()

Runs one Tavily web search.

NameTypeDescription
inputquerystrThe search text.
inputmax_resultsintMaximum number of results to request. Default 5.
outputlist[str]The text snippet from each result; empty results are skipped.
